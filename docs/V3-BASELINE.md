# V3 升级基线

2026-10-08 检查：工作区干净，V2 提交 `16de7f5`，已保留 `startflow-v2.0-baseline` 标签，新分支 `codex/startflow-v3`。应用和 SQLite 版本分别 2.0.0 / 2；内部旧配置版本 1、工作流版本 1、导出包版本 2。

代码实际存在：V1 Task Launcher、Rust Scheduler / 持久化自然日去重、托盘 / 单实例 / 自启；V2 图验证与后台执行、条件、取消 / 超时、Win32 布局、官方全局快捷键、独立命令面板、管理目录背景、模板、备份与合并恢复。旧报告记录 13 项前端、32 项 Rust、26 项 V1 回归、19 项 V2 原生、6 项界面和 3 项安装升级通过；这些是历史证据，不能代替 V3 回归。

待验证的原有限制：真实重新登录、物理双屏 / 混合缩放 / 拔屏、睡眠、长期性能、第三方受限窗口；签名和在线更新未配置。V3 不把它们改写为已通过。

升级顺序：事务迁移及一致性备份 → 强类型环境与原生事件 → 四值条件树和确定性决策 → 持久化去重 / 冷却 / 覆盖 → 同引擎 Dry Run / 历史回放 → 工作模式 / 隐私 / 规则界面 → 受控 AI 草稿服务 → 回归、原生验证和 NSIS。

保留全部旧表；新增规则、模式、有限环境摘要、事件、决策、覆盖、权限和 AI 草稿。所有 V3 运行调用既有 engine::submit_scene_with_workflow，继续同场景互斥、有界并发和自动自然日去重。新自动执行默认关闭，未知信息不授权执行。Provider、模拟器和 AI 不调用 Task Launcher。

Windows Wi-Fi 当前连接查询受定位权限限制，只在显式开启后使用；不扫描周边网络，不读取密码 / BSSID。依据：[微软 Wi-Fi 权限变化](https://learn.microsoft.com/en-us/windows/win32/nativewifi/wi-fi-access-location-changes)。
