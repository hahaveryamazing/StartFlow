# StartFlow V2 Windows 手工验收

本清单是待用户桌面实测步骤，不代表已经通过。已执行的自动化结果另见 [实际测试报告](V2-TEST-RESULTS.md)。先导出配置并确认 `backups` 中存在恢复副本；测试程序路径必须由测试者选择。窗口、启动和快捷键操作均不要求管理员权限，不绕过 UAC。

## 安装与数据升级

1. 在 V1 创建场景、网页 / EXE / 文件夹任务、顺序、每日及星期规则和日志，设置主题。
2. 彻底退出 V1，安装 `release/StartFlow_2.0.0_x64-setup.exe`。
3. 在设置查看同一数据目录；核对每项配置、历史和实际自启状态，确认升级 SQLite 副本。迁移不自动切换高级模式。
4. 另在隔离测试目录复制 V1 库，模拟不可写 / 损坏库。应明确报错，保留原文件，不生成空库替换。不要用生产库进行损坏测试。

## 工作流与分支

1. 为测试场景转换草稿，原任务列表应保留。创建开始 → Bing 网页 → 3 秒延迟 → 测试 EXE → 结束；配置自己的程序路径。
2. 保存、验证、测试运行。核验浏览器和实际程序启动请求、节点时间及真实日志。正式执行首次确认后才激活高级模式。
3. 配置完整 EXE 路径的进程条件，各分支连接自己的结束节点。分别让程序运行和停止，检查 True / False 路径及未选分支跳过。
4. 用不可访问路径和不可达 HTTPS 服务测试。网络不通应超时 / False；权限、证书或配置错误应显示 error，不能当作普通 False 继续。
5. 尝试循环、缺少结束、重复 True 分支、无效 URL / 程序路径 / 条件 / 布局引用。保存或运行前应明确拒绝。
6. 使用 30 秒等待，运行后关闭主窗口。托盘打开后查看持续运行；取消等待后不得执行之后的程序，不终止已提交的第三方程序。
7. 受控终止测试进程后重新启动，历史应 interrupted，不自动从中间继续；检查补执行和自然日去重。

## 窗口布局与显示器

1. 打开两个普通非管理员桌面程序，手工选择顶层窗口并保存布局。
2. 移动、缩放、最小化窗口，恢复布局，肉眼和日志读回核验位置、尺寸、最大化及工作区可见性。
3. 双屏设置不同分辨率和 100% / 150% / 200% 缩放，主副屏交换位置后恢复。核验窗口未被缩放两次、未落到任务栏或屏外。
4. 保存双屏布局后实际断开副屏。分别测试主屏回退、跳过和备用布局，窗口应保持可见或明确跳过。
5. 同一 EXE 打开多个窗口，用标题规则区分；模糊匹配应报错。动态标题、管理员程序、全屏或禁止调整大小程序，应合理失败，不提升权限。
6. 浏览器标签页不是独立 Windows 窗口；本功能不承诺逐标签移动。

## 快捷键与命令面板

1. 录制空闲组合键保存，隐藏主窗口后按键启动场景，检查真实日志。打开快速命令面板，搜索、上下键选择、Enter、Esc 及失焦隐藏。
2. 重复按命令面板快捷键，不应创建新窗口或初始化新调度器。
3. 配置重复组合或让另一个软件占用组合。应明确注册失败，保留原可用快捷键，不显示假成功。
4. 修改、禁用、删除快捷键，检查旧组合立即释放；重启后恢复新注册。删除快捷键对应场景后旧组合也必须注销。
5. 恢复默认应清除自定义组合，不预占用示例键。

## 调度、登录与托盘回归

1. 原生文件选择器选择包含中文和空格的 EXE / LNK / 文件夹，填写分离参数及工作目录；Bing 使用默认浏览器。非法路径失败不终止其它简单任务。
2. 设置将到的每日规则，关闭主窗口，实际到点后观察日志和目标程序；星期规则只在勾选的本地星期触发。
3. 同日通过不同自动规则触发同一场景，最多执行一次；手动可再次运行但不能与正在执行的同场景重入。
4. 开启真实登录自启后查询状态，退出并重新登录 Windows，验证自动启动默认隐藏、登录延迟和场景规则。手动启动不能重复执行登录规则。
5. 设置快到时间的任务后睡眠，错过时间并唤醒，分别验证关闭补执行 / 30 / 120 分钟窗口和去重。改变系统时间、跨午夜和本地时区后复测；如用夏令时地区，测试缺失及重复小时。
6. 鼠标验证托盘打开、默认 / 最近场景、快速面板、暂停 / 恢复、设置和真正退出；重复打开程序只显示已有实例。
7. 彻底退出时计划不会独立触发。重新打开只按补执行规则提交整个场景，不恢复任意中间节点。

## 主题、模板与恢复

1. 深浅 / 跟随系统、5 种预设、自定义强调色、圆角、密度、动画分别保存并重启。
2. 原生选择 PNG / JPEG / WebP，改变透明度、模糊、显示方式；移动原图应保留副本。无效 / 超大 / SVG 图片拒绝；丢失副本应回退正常背景。
3. 默认模板配置自己的任务及布局，预览并保存为个人模板；重命名和删除应持久化。模板不隐式执行。
4. 配置每日 / 每周自动备份和保留数量，在测试日期检查真实文件和记录；删除只针对所选管理目录备份。
5. 导出带工作流、布局、背景、模板和快捷键的 JSON，预览并合并。UUID 冲突应映射引用，当前主题及快捷键保留，导入快捷键停用。
6. 完整替换必须两次确认，先创建当前备份；恢复后自动任务暂停、快捷键停用，不立即执行内容。检查实体引用和程序路径后主动恢复。
7. 系统通知开关应影响实际提示；通知内容和节点结果不能伪造任务成功。

## 发布、卸载与性能

1. 干净 Windows 用户安装 / 修复 / 更新 / 卸载，验证 WebView2 缺失引导。默认卸载应保留数据，只有明确删除选项才删除；不使用现有生产配置测试删除。
2. 100 节点编辑、缩放和连线，记录设备信息与响应；后台隐藏至少 1 小时记录 CPU、内存、唤醒和数据库写入。测试连续多日调度、窗口恢复和热键响应。
3. 缺少网络时本地场景、SQLite 和主题继续工作；网络节点按超时结束。未配置可信签名源时不展示可用在线更新。
