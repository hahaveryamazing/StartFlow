# 测试与 Windows 人工验收

自动化命令与环境见 README。自动化报告使用真实窗口、RPC、SQLite 和 EXE 回执，网页和文件夹测试仅能自动确认系统接受请求，不等同于确认目标窗口内容。

以下项目必须由 Windows 桌面用户观察，未执行前不得标记为通过。

| 验收 | 操作 | 预期结果 |
|---|---|---|
| 默认浏览器 | 添加 `https://www.bing.com`，点击任务“测试运行” | 默认浏览器显示该 URL；日志“请求已提交” |
| 原生程序选择器 | 新建应用任务，点击“选择”，选取本地 EXE；设置独立参数和工作目录 | Windows 文件选择器可选择 EXE；目标收到启动请求 |
| LNK 和文件夹 | 通过选择器添加带中文和空格的 LNK、文件夹；分别测试 | 快捷方式目标打开；资源管理器显示正确文件夹 |
| 完整场景 | 添加两个网页和一个 EXE，设置 2 秒延迟；拖动改变顺序并保存；一键运行 | 任务依次提交；详情名称、顺序和状态吻合；错误路径不阻止后续任务 |
| 托盘 | 关闭主窗口，右键 StartFlow 托盘图标，使用打开、最近场景、默认场景、暂停 / 恢复、系统设置、退出菜单 | 隐藏后进程仍存在；菜单真实生效；点击打开恢复原窗口；退出真正结束进程 |
| 真实重新登录 | 开启登录自启，配置登录规则；保存工作后退出 Windows 并重新登录 | StartFlow 后台启动；默认不显示主窗口；延迟后运行一次；重复手动打开只聚焦已有实例 |
| 每日定时 | 设置即将到来的 HH:mm，隐藏窗口，等到目标时间 | 后台进程实际提交任务并落库，不能只观察 UI 倒计时 |
| 每周定时 | 选择今日星期与即将到来的时间，再测试一个未选择的星期 | 今日规则到点执行；不匹配星期不执行 |
| 睡眠恢复 | 配置未来计划，睡眠跨过计划时间；在 30 / 120 分钟窗口内恢复，再测试窗口外或关闭补执行 | 窗口内最多补执行一次；窗口外不执行；同日重复规则不重复执行 |
| 时间 / 时区变化 | 在专用测试机器改变系统时间或时区，不修改日常机器 | 调度按当前本地时间重新检查，日期与规则发生记录仍防止重复 |
| 暂停与恢复 | 暂停自动任务，跨过计划时刻，恢复 | 暂停时无新自动执行；恢复按补执行窗口检查；手动任务可运行 |
| 持久化 | 保存主题、任务参数、默认场景及规则；彻底退出，再打开 | 数据保持；手动打开不无条件执行登录规则 |
| 通知 | 启用通知，运行成功与错误任务，观察 Windows 通知中心 | 显示中文结果；关闭通知后不显示；请求提交不表示第三方已就绪 |
| 导入导出 | 导出、删除场景、导入；检查覆盖确认、稳定关系和顺序 | 数据正确恢复；导入后自动任务暂停；错误文件不改变现有数据 |
| 安装与卸载 | 运行 x64 NSIS；打开开始菜单入口；卸载时不勾选删除数据，再重新安装 | 安装与入口可用；无提示删除配置的行为；再安装读取原数据 |

支持的自动化并不能代替不同 Windows 版本、用户权限、安全软件、缩放比例、网络状态、网站、快捷方式目标和第三方程序的实际验收。完成验证后，应在 `docs/TEST-RESULTS.md` 中记录系统、日期、步骤及真实结果。
