# V3.1 界面修复交付

2026-10-10。保留第五阶段能力，增量修改，无数据库迁移。

## 修复

- 左右滚动容器明确限制高度；旧版安装实例是用户持续无法滚动的实际原因之一。更新安装后用户已确认物理滚轮可用。详见 [滚动回归](SCROLL-REGRESSION.md)。
- 滚动条活动时约 40% 不透明度，空闲 1.2 秒后隐藏；不拦截滚轮。
- 点击强调色打开应用内面板；HEX、RGB、预设与即时预览通过统一事务保存，不重建已有工作流或登录授权。详见 [外观测试](APPEARANCE-FIX.md)。
- 工作台最近登录记录原先依赖按需加载的桌面登录页面 CSS，首次进入工作台时缺失 padding 与换行保护。现提取为入口全局样式，增加 20px 内边距、24px 卡片下间距和长文本换行。
