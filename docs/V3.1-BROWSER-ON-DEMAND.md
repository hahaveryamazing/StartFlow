# V3.1 第二阶段增量：浏览器按需准备

基于 `30fe3ee` 增量修改，分支 `codex/startflow-v3.1-browser-on-demand`。仅优化第二阶段浏览器部署；没有进入录制器或自动登录工作流集成阶段。数据库保持版本 5，无新增迁移，不更改生产库或密码存储。

## 用户行为

1. 首次运行及后续启动时，Rust 后台在已知 Windows 安装目录检测 Edge、Chrome，优先 Edge。没有读取浏览器日常 Profile、Cookie、密码或访问历史。
2. 存在 EXE 只是候选。使用空的临时 Profile 实际启动浏览器，并验证 CDP 和响应拦截能力；失败则尝试下一个浏览器，成功才显示就绪及实际版本。
3. 检测同时覆盖应用数据目录中已下载的固定版本 Chromium。没有可用浏览器时，「网页登录」显示下载入口；用户确认后从官方来源准备专用浏览器。下载不会登录、提交密码、改变默认浏览器或安装系统级服务。
4. 显示检测中、准备中、可用、缺失、失败、取消状态。没有伪造百分比。下载可取消、重试；退出程序清理受控子进程。最长检测 50 秒，准备 8 分钟；单次下载连接超时 30 秒。
5. 每个账号始终使用独立持久 Profile。Edge、Chrome、专用 Chromium 的资料目录互相隔离，避免不同浏览器的本地加密格式冲突。切换类型可能需要重新登录；保留旧目录，不迁移日常 Cookie。

## 部署与安全

安装包包含固定 Node 24.16.0、Playwright 1.64.0、私有登录 worker、准备服务和许可证；**不包含浏览器本体**。Tauri 资源清单明确列出这些文件，排除旧 `browsers/` 和 `.test-runtime/`。构建准备拒绝残留在依赖内的 `.local-browsers`，防止意外携带浏览器。

Rust 只接受“检测或下载”的布尔选项；前端不能指定 EXE、Profile、下载 URL、CLI 参数或环境变量。准备服务只收到后端生成的已知候选路径及缓存目录，拿不到账号和凭据。返回结果按后端候选或固定缓存路径再次校验，普通页面不接收执行路径。两个新增 IPC 同样限于主窗口和可信 Origin。

下载由随包的固定 Playwright CLI 执行 `install chromium --no-shell`，使用官方默认 HTTPS 下载源及包内固定 revision（1248），不接受下载镜像或环境中的任意命令。验证下载后浏览器能够受控启动，再标记就绪。TLS 与官方来源是当前下载信任机制；不宣称另有独立浏览器产物签名或离线校验公钥。

Node 与浏览器进入 Windows Job Object；下载在后台，主窗口隐藏不影响它。取消、超时或程序退出终止受控进程，不终止用户日常浏览器。只允许一个准备操作，账号浏览器打开时禁止切换运行时。秘密仍由 Windows Credential Manager 管理，仅在用户授权的单次私有管道请求中读取；原有 HTTPS/Origin/表单保护、一次提交、冷却和人工验证策略保持。

资料目录相对于设置显示的应用数据目录：

| 内容 | 目录 |
| --- | --- |
| 按需浏览器及临时探测 | `browser-cache/` |
| 专用 Chromium 账号资料（兼容旧目录） | `browser-profiles/<账号 UUID>/` |
| Edge 账号资料 | `browser-profiles/edge/<账号 UUID>/` |
| Chrome 账号资料 | `browser-profiles/chrome/<账号 UUID>/` |

浏览器缓存和账号 Profile 不进入 SQLite 配置备份、普通 JSON 导出、AI 上下文或日志。缓存准备不清理旧账号数据。没有浏览器或网络不可用只影响网页登录，旧启动场景、调度与工作流继续可用。

当前实际检测到 **Edge 154.0.4258.62**，成功使用独立 Profile 完成本地 HTTPS 登录及 Cookie 复用。原生测试随后通过仅调试版可用的开关隐藏已装候选，在全新隔离缓存中实际从官方下载 **Chromium 156.0.8078.4**，验证准备阶段未登录，完成后实际登录并复用会话。没有改动或删除真实 Edge 安装，也没有使用真实网站账号。证据：[原生结果](web-login-on-demand-native-results.json)。

曾因 C 盘空间不足导致首次测试复制和 Rust 链接失败；使用 Cargo 清理本项目可再生成的缓存后重测通过。发现生产 StartFlow 正在运行时暂停原生测试，用户从托盘退出后才运行；测试使用单独 SQLite、合成账号及临时 Profile。未升级已安装的生产应用。

## 产物及限制

实际精简安装包：[StartFlow_3.1.0_browser-light_x64-setup.exe](../release/StartFlow_3.1.0_browser-light_x64-setup.exe)，**30,696,422 字节 / 29.27 MiB**。此前完整浏览器版为 172.98 MiB，缩小约 83%。SHA-256：`1de84878ee2ae21a1fdf2b75de67d40840dda722b4a320ce0e41a28bd08f46dc`；[构建清单](../release/StartFlow_3.1.0_browser-light_manifest.json)。旧交付包保留。

浏览器下载后的磁盘空间仍需数百 MB；精简减少的是安装包传输和已有浏览器时的重复安装。企业策略、浏览器升级或非标准安装位置可能无法通过检测；可尝试专用浏览器。Chrome 实际登录未在本机实测（没有检测到 Chrome），对应检测回退由确定性测试覆盖。

精简 NSIS 未签名，尚未安装/卸载验收。实际网站、扫码、实体 MFA/Passkey、企业代理和长期后台资源使用仍待目标环境验证；同 Origin HTML POST 的支持边界与 [原登录安全限制](V3.1-WEB-LOGIN.md) 一致。

参考：[Playwright 支持已装 Edge / Chrome 及企业策略限制](https://playwright.dev/docs/browsers)、[持久 Profile 与日常资料限制](https://playwright.dev/docs/api/class-browsertype#browser-type-launch-persistent-context)。
