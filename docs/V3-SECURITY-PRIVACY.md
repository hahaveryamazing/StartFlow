# V3 安全与隐私说明

## 默认值

旧自启和调度配置原样保留。新增智能自动化关闭；Wi-Fi、持续进程检测、指定服务探测、AI 默认关闭。新规则禁用并默认请求确认；自动执行和自动模式需要用户明确启用。无需 AI、网络账号或云服务即可使用核心本地功能。

## 环境数据

应用内开关仅表示用户允许检测，不等于 Windows 已授权。当前字段独立表示 available、unavailable、permission_denied、unsupported、error；条件结果区分 true、false、unknown、error。SSID 不可读不会被解释成“未连接指定网络”。

Wi-Fi 仅查询当前已连接接口，不调用附近无线网络扫描；不存密码、原始 MAC 或 BSSID。当前 SSID 只在授权后的内存 / 当前界面出现；信任 SSID 使用当前 Windows 用户 DPAPI 加密，别名由用户自定义。历史快照清除原始 SSID，仅保留信任网络 UUID。密文跨用户 / 设备失效时显示错误或未知，需要重新配置。

显示器读取工作区、分辨率、排列、主屏和缩放；电源读取系统提供的供电和电池状态，无电池设备明确不适用。会话通知只注册当前用户会话，不把窗口聚焦当系统解锁。进程只检查启用规则指定的路径；不记录所有应用使用历史、键盘、屏幕、聊天内容或浏览器历史。

HTTPS 探测只访问用户配置并启用的服务，有限超时且不跟随重定向；本地网络接口连接不等于互联网或特定服务可达。

## AI

Windows Credential Manager 保存用户范围的 API Key。SQLite / JSON 导出仅有凭据引用，普通读取命令不返回密钥；前端仅在用户录入时短暂持有输入，提交后清空。请求由后端发送，错误不回显密钥。设置提供删除入口，跨设备必须重新配置。

AI 默认关闭，无内置免费模型。支持用户已启动的本地兼容服务和用户配置的云端 HTTPS 服务。先展示精确请求 JSON，用户确认后才发送；默认不发送 Wi-Fi、运行日志、文件内容、全量应用清单或所有场景。只发送当前需求、明确选中的关联配置和必要 Schema。用户自己的提示、选中规则或主动开启的历史上下文也可能含私人内容，应在预览中检查。

输入、响应、连接 / 总耗时均有限；禁止重定向、任意工具调用、脚本 / DLL 节点和未支持字段。外部文字与模型响应均视为不可信数据。生成的草稿可以修改，缺失路径 / URL / 引用不能保存为有效执行配置；AI 不猜测本地路径。正式提交仍验证，规则强制禁用并采用确认策略，工作流强制禁用，用户需要手动激活和运行。

## 执行与数据

URL 仅 HTTP / HTTPS，程序路径和参数独立，不拼接 CMD、PowerShell 或任意 Shell。不自动请求管理员权限，不绕过 UAC，不下载执行远程程序，不存网站密码。AI 没有执行接口，Provider 与模拟器不能启动任务。

capabilities 限制在应用受信任本地窗口。远程网页只通过系统浏览器启动，不载入高权限 WebView。受限第三方窗口降级报错，不进行权限绕过。

环境历史默认 30 天并有数量上限；一键清理仅删除环境决策摘要，不删除规则 / 场景或持久化去重状态。常规日志不回显不必要的完整系统错误。用户明确录入的场景路径仍属于本地配置，可包含个人信息，因此备份文件应由用户妥善保存。

升级和恢复先备份、验证引用并事务写入；失败回滚，不生成空库覆盖旧库。导入不执行，敏感权限需要重新确认。没有遥测、默认上传、系统级服务或后台屏幕采集。
